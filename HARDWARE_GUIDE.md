# SilentSpeak AI - Hardware Setup Guide

## Components Required

| Component | Purpose | Qty |
|-----------|---------|-----|
| ESP32 DevKit V1 | Microcontroller, reads EMG + sends data | 1 |
| EMG Muscle Sensor V3.0 | Amplifies muscle signals | 1 |
| EMG Electrodes | Stick to skin, pick up muscle signals | 3 |
| Webcam | Captures lip movements | 1 |
| PAM8403 Amplifier | Boosts audio for speaker | 1 |
| Speaker (4-8Ω) | Outputs synthesized speech | 1 |
| Breadboard | Prototyping | 1 |
| Jumper Wires | Connections | 10+ |
| USB Cable | Powers ESP32 + data to PC | 1 |
| Power Bank (5V) | Portable power for expo | 1 |
